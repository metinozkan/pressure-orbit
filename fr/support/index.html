Indique ton appareil, la version de l’app et ce qui s’est passé. N’envoie jamais de mot de passe, de carte bancaire ou de code de connexion.

Contacter l’assistance

Achats et abonnements

Restaure les achats dans l’app avec le même compte Apple ou Google. Gère ou résilie l’abonnement dans les réglages de la boutique. Supprimer l’app ou le compte de jeu ne résilie pas un abonnement. La boutique gère les remboursements.

Progression en invité

Jouer, acheter, restaurer les achats et gérer les abonnements ne nécessite aucun compte de jeu. L’identité invitée peut être perdue après désinstallation ou changement d’appareil. Les achats se restaurent avec le compte d’origine de la boutique.

Demander la suppression

Dans l’app actuelle, ouvre Réglages → Changer le nom du pilote → Supprimer mon pilote. La suppression confirmée concerne les invités et les comptes liés, sans résilier les abonnements. Si ta version ne propose pas cette option, contacte l’assistance. La propriété est vérifiée avant le traitement. Indique ton nom de pilote et l’e-mail lié, le cas échéant. Nous pouvons demander des informations limitées pour vérifier la propriété. N’envoie jamais ton mot de passe. Nous expliquerons les données à conserver pour des motifs légaux ou de sécurité.
